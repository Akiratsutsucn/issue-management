## 已知偏差与决定

| 项 | 决定 |
|----|------|
| 认证没有用 Auth.js | 自建数据库会话：令牌只存在 cookie，库内保存 HMAC；会话 14 天；重置密码或停用账号会清除会话 |
| 导入的「已回答」行不写首次回答日 | 源表没有回答日期。若用记载日代替，响应统计会变成 0 天。留空后由用户在详情补录 |
| 提醒计算方式 | 进程内定时器（15 分钟，可设 15–30）+ 写入后异步刷新。邮件、企微为二期 |
| 附件存储 | 本地 volume；`STORAGE_DRIVER=s3` 接口已预留，二期实现 |
| 只读角色 | 二期 |

## 审核发现与处理

| 级别 | 问题 | 处理 |
|------|------|------|
| HIGH | 登录失败计数是先读后写，并发请求可以绕过锁定 | 改为原子自增 |
| HIGH | 部分页面只依赖 layout 鉴权 | 每个页面单独调用 `requireUser()` |
| MEDIUM | 改名为 .txt 的音频可以上传 | 校验文本内容，并补充 MP3 帧、AAC、FLAC、ASF、FLV、AMR、MPEG 的文件头 |
| MEDIUM | 导入时「未完成」被识别为完成 | 先判断否定词 |
| MEDIUM | 覆盖策略会把默认优先级、确认类别、标题待补标记写回已有课题 | 默认值不再覆盖已有数据 |
| MEDIUM | 同一导入任务重复提交会执行两次 | 原子认领任务 |
| MEDIUM | 批量追加担当时，遇到已停用担当会中断 | 改为逐条容错，只新增担当关系 |
| 规格 | 锁定提示暴露邮箱是否存在；锁定阈值不可配置 | 锁定与普通失败统一提示；阈值和时长可在设置中修改 |
| 规格 | 列顺序不可调；部分扩展字段不能作为列 | 已补齐 |
| 规格 | 会谈导出缺少来源文档、分工建议、出席 | 已补齐；按客户导出增加「会谈/批次」列 |
| 规格 | 导入关联失败会回滚整次导入；导入新建客户绕过设置、不写日志 | 关联移到主事务之后单独建立；新建客户受设置约束并写日志 |
| 构建 | standalone 产物缺少 exceljs 动态加载的依赖，导出返回 500 | 通过 `outputFileTracingIncludes` 带上；e2e 复测导出通过 |
